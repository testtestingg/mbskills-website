# MBS Skills

Corporate education website for MBS Skills, a digital training center in Tunis.

The public homepage presents the training fields, featured programs, teaching approach, learner feedback, and contact flow in French, English, and Arabic.

## Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS 4
- Lucide icons

## Local development

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm start
```

## Deployment

The repository is configured for Vercel. Merging into the production branch triggers the project’s connected deployment workflow.
